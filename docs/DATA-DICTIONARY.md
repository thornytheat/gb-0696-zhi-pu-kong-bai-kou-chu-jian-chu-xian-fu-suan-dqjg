# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。

## 委托方归属与双编号

仪器文件入库时按物理行登记委托方归属（`runs.attribution`，键为物理行号）。
显式登记支持整文件 `client_id` 或行级 `line_clients`；未登记的数据行一律标记
`UNASSIGNED`，系统不猜测归属。升级前的旧记录无归属列时按未归属处理：实验室
仍可复核全部原始记录，但任何委托方导出都会被拦截，避免猜错归属导致整行泄露。

样品采用双编号：
- 原始样品编号（仪器文件中的 sample_id）只保留在实验室内部记录与全量证据中；
- 委托方证据使用机构内稳定别名（`sample_aliases`），形如 `CL-ACME-S000001`，
  序列号按委托方各自递增。同一委托方同一原编号永远映射同一别名，可跨历次导出
  核对测值；不同委托方的别名空间互不相干，仅凭别名无法跨机构串联样品历史。
- 无样品编号的隔离行（坏列、重复表头）以 `__line__<物理行号>` 作为别名键。

委托方证据只含本机构行，manifest 声明本机构可见口径；其他机构行完全不可见且
不计入对账数，未归属行计数并阻断导出。隔离行的 reason 码随证据输出，委托方
可核对每行被隔离的原因。导出登记 `exports` 以 (run_id, client_id) 为主键，
重试导出不新增登记、不新增别名。
